# Content Credits and Attribution

The interpretive content in this directory is drawn from classical Sanskrit Vedic-astrology texts that are public domain, alongside a smaller set of source-verse renderings adapted from the open-source **Maitreya** project.

## Source texts (public domain)

The classical verses cited throughout this directory are translations of public-domain Sanskrit works:

- *Brihat Parasara Hora Sastra* (BPHS) — attributed to Maharshi Parasara
- *Phaladeepika* — Mantreswara
- *Brihat Jataka* — Varahamihira
- *Saravali* — Kalyanavarman
- *Jaimini Sutras* — attributed to Maharshi Jaimini
- *Sripati Paddhati* — Sripati Bhatta

The English translations consulted are:

- BPHS — R. Santhanam (Ranjan Publications)
- Phaladeepika — V. Subrahmanya Sastri (1950, 2nd edition)
- Brihat Jataka — Swami Vijnananda (Government of India / Archaeological Survey)
- Saravali — V. Subrahmanya Sastri (1928, Pandurang Jawaji / Nirnaya Sagar Press)
- Jaimini Sutras — B. Suryanarain Rao
- Sripati Paddhati — V. Subrahmanya Sastri (1934)

## Adapted from Maitreya

Source-verse content marked with `via: Maitreya` in the entry frontmatter is adapted from the **Maitreya** Vedic-astrology software project, authored by **Martin Pettau**, available at [saravali.de](http://www.saravali.de) and [github.com/martin-pe/maitreya8](https://github.com/martin-pe/maitreya8).

Maitreya is licensed under the **GNU GPL v2.0 or later**. The COPYING file in the Maitreya distribution states: *"The software is Open Source and free for private and commercial use."*

The classical verses themselves are public-domain Sanskrit scripture; the specific English renderings in Maitreya's data files reflect work by Pettau and the Maitreya contributor community.

## How adaptation works in this repository

Each entry that draws on Maitreya keeps the original source verse verbatim in a `## Source verse` body section, with the verse marked as adapted from Maitreya. A second body section, `## Rendering`, holds Dr. Vinay Kumar Chaganti's own rephrasing of the verse in the researcher's voice — written by hand against the source. The rendering is the layer published to the chart UX; the source verse is retained as the canonical reference and is available on the chart as an "Original source" expandable.

Where the rephrasing has not yet been authored, the chart UX falls back to displaying the source verse with attribution. The two-track structure is a deliberate compromise between license respect and editorial control: the source verse is preserved as-is to honour Maitreya's contribution; the rendering layer is original work.
